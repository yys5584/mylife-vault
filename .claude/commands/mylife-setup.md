# /mylife-setup

질문 12개를 4개씩 3라운드로 던져서 `templates/` 안 마크다운을 채운다. 10분이면 끝난다.

포지션: 응답의 1순위 근거는 사용자가 직접 입력한 문서. 사주·별자리는 운세 수준의 참고 톤이며 선택이고, 명시 요청 시에만 답변에 반영한다. 자세한 룰은 `CLAUDE.md`의 "사주·별자리 — 위치 정의" 참조.

## 진행 규칙 (이걸 어기면 10분 안에 못 끝난다)

- 질문은 라운드 단위로 4개씩 한 번에 던진다. 하나씩 쪼개지 않는다.
- 답을 받으면 바로 다음 라운드로 간다. 살 붙이는 되물음 금지.
- 질문 총량 12개가 상한이다. 더 궁금해도 인터뷰 중에는 안 묻는다.
- "패스" / "모름"이면 빈 칸으로 두고 넘어간다.
- 페이스 선택지, 분할 진행 제안, 섹션 메뉴를 띄우지 않는다. 인사 한 줄 하고 바로 라운드 1.
- 라운드가 끝날 때마다 해당 파일을 저장한다.
- 톤은 코칭 파트너. 분석가 톤 금지. 추상 조어(엔진·갈래·격차 같은 것) 금지. "또한·이를 통해·따라서" 금지. "본인" 대신 호칭이나 "사용자".

시작할 때 띄우는 문구:

```
질문 12개, 4개씩 세 번 물어본다. 10분이면 끝난다.
모르는 건 "패스" 하면 빈 칸으로 두고 넘어간다.
```

## 라운드 1 — 지금 나 (3분)

채우는 곳: `templates/self_profile.md`

```
1. 양력 생년월일 / 성별 / 지금 사는 동네
2. 지금 하는 일 + 돈이 들어오는 구조 (월급·사업·투자·없음)
3. 내 강점 3개 + 각각 10점 만점에 몇 점
4. 내 약점 3개 + 각각 10점 만점에 몇 점
```

답이 막혔다고 하면 힌트 한 줄만 준다. 되물음이 아니다.

- 3번: 남들이 자주 칭찬하는 것 + 내가 자랑하고 싶은 것
- 4번: 같은 실수로 반복해서 걸리는 지점

## 라운드 2 — 어디로 가나 (4분)

채우는 곳: `templates/philosophy.md`, `templates/life_compass.md`

```
5. 인생에서 1순위 한 단어 (자유 / 돈 / 동반자 / 명예 / 가족 / 성장 / 안전 …)
   + 그게 1순위인 진짜 이유 한 줄 (어디서 왔는지 솔직하게)
6. 그거 이루면 어떤 장면인가 — 그날 아침 눈뜨면 뭐가 보이나 (한 줄, 구체적으로)
7. 2순위·3순위 한 단어씩
8. 5년 뒤 나는 어디서 누구랑 뭘 하고 있나 (한 줄)
```

5번과 6번이 vault 전체의 방향타다. 비면 자기 진단도 로드맵도 어디로 가려는지 모르는 채로 굴러간다. 다른 걸 패스해도 이 둘은 받아낸다. 사용자가 5번을 비우면 딱 한 번만 "이거 없으면 죽는다 싶은 거 한 단어"로 다시 물어본다.

```
9.  내가 반복하는 루프 — 어떤 상황에서 → 뭘 하고 → 어떻게 끝나나 (한 줄)
10. 무너지기 직전에 나타나는 신호 2~3개 (수면·소비·충동 같은 거)

12. 이번 분기 목표 3개 (3개월 뒤에 "이거 했으면 성공"인 것)
```

## 답변 뒤 자동 처리

1. 나이를 생년월일에서 계산해 `self_profile.md`에 넣는다.
2. 도출형 항목 3개는 후보 2개를 만들어 제시하고 사용자가 고르게 한다. 지어내서 확정하지 않는다.
   - 정체성 한 문장 ("나는 [무엇]을 하는 [어떤] 사람이다")
   - 5년 북극성 한 줄
   - 핵심 한 줄 (`self_profile.md` 맨 위 요약)
3. 답에 안 나온 사실 항목(출생 시간, 진단명, 가족 구성 등)은 비워 둔다. 추측해서 채우지 않는다.
4. 문서 간 같은 항목을 같은 문장으로 맞춘다.
   - `philosophy.md`의 정체성 한 문장 = `life_compass.md`의 정체성 한 문장
   - `self_profile.md`의 강점·약점 = `life_compass.md`의 강점·약점 표
   - 안 맞으면 어느 쪽으로 통일할지 한 줄로 묻는다.
5. 남은 placeholder 개수를 세어서 보고하지 않는다. 채워진 것으로 답하고, 필요할 때 한 줄로 물어본다.

## 인터뷰 마지막 — 보고서 출력 (필수)

인터뷰가 끝나면 셋업 완료 보고서를 출력한다. 사주 앱에서 받는 풀이 보고서처럼 읽혀야 한다. 답변을 정리해서 돌려주는 문서가 아니라, 짧은 답을 근거로 그 사람을 풀어주는 문서다.

### 문체 — 합니다체 사주풀이

보고서와 영역별 풀이는 일반 대화와 문체가 다르다. 이 둘에 한해 CLAUDE.md 워딩 룰의 1인칭 "나" 주어 대신 아래를 따른다.

- 합니다체. "~한 기질을 타고났습니다", "~하는 편입니다", "~할 때 빛납니다"
- 주어는 대부분 생략한다. 꼭 필요하면 "당신은"을 쓰되 한 카드에 한두 번까지. "사용자는"·"본인은" 금지
- 결을 읽어주는 어조. "~입니다"로 끝나도 판결이 아니라 풀이로 들리게 쓴다
- 나머지 워딩 룰(분석 비유 금지, 즉석 조어 금지, 본문 숫자 금지, 단문 끊기 금지)은 그대로 적용

### 보고서 구조

맨 위 총평 → 영역 카드 → 종합. 카드는 채워진 문서에 따라 가감한다. 근거 문서가 비어 있으면 그 카드는 만들지 않는다.

| 카드 | 근거 문서 | 첫 소제목 |
|---|---|---|
| 🧠 기질 | self_profile | ■ 타고난 기질 |
| 🎯 인생의 방향 | philosophy | ■ 마음이 향하는 곳 |
| ⚙️ 생활의 흐름 | life_os · life_compass · roadmap | ■ 지금의 흐름 |
| 💞 관계·애정 (해당 시) | love_style · relationship_protocol | ■ 관계의 결 |
| 💼 일·재물 (해당 시) | career_style · investment_style · side_project_strategy | ■ 일과 재물의 결 |

10분 인터뷰만 마친 상태면 기질·방향·흐름 카드 3장과 종합이 나온다. 관계·일 카드는 메뉴에서 해당 영역을 채운 뒤에 붙는다.

### 총평 형식

```
# 인생 설계 풀이

> [한 문장 총평]

키워드 · [3개를 가운뎃점으로]

[2~3문단. 이 사람의 큰 결 → 무엇을 향해 가는지 → 지금 어디서 막혀 있는지]
```

### 카드 형식

```
## 🧠 기질

> [한 줄 요약]

| 항목 | 값 |
|---|---|
| ... | ... |

■ 타고난 기질
[2~3문장]

■ 잘 풀리는 자리
[2~3문장]

■ 조심할 자리
[2~3문장. 위험 신호와 연결]

■ 지금 필요한 것
[1~2문장. 처방은 vault 자체 약점에서만 도출]
```

- 데이터 박스는 표 하나. 숫자·점수·날짜는 여기에만 둔다
- 소제목은 ■ 네 개로 고정. 첫 소제목만 카드마다 다르고 나머지 셋은 공통
- 한 소제목 안은 2~3문장. 길어지면 줄바꿈으로 호흡만 준다

### 풀이 전개 — 답을 되돌려주지 말고 푼다

사주에서 일간 하나로 사람을 한참 풀어주듯, 짧은 답 하나를 소제목 네 개로 풀어낸다.

- "강점: 자기인식"이라는 답을 "자기인식이 강합니다"로 끝내지 않는다. 그 기질이 평소 어떤 장면으로 나오는지, 어디서 성과로 바뀌었는지, 어디서 같은 기질이 짐이 되는지까지 간다
- 강점과 약점을 따로 나열하지 않고 한 기질의 양면으로 엮는다
- 일반 패턴("이런 기질을 가진 사람은 보통")은 아래 외부 레퍼런스에 출처가 있을 때만 쓴다. 없으면 쓰지 않는다

### 정량 지표 룰 (숫자는 출처가 있을 때만)

데이터 박스에 넣는 숫자는 세 종류뿐이다. 이 셋 밖의 숫자는 만들지 않는다.

**1. 자기평가 점수 (1-10)** — 인터뷰 Q3·Q4에서 사용자가 직접 매긴 점수. 검사 결과가 아니라고 한 번 밝힌다.

**2. 추정 백분위** — 밖에서 검증 가능한 실적이 있는 항목에만 근거와 함께 붙인다. 템플릿에 저장하지 않고 보고서를 뽑는 시점에 계산한다. 실적이 바뀌면 값도 바뀌기 때문이다.

| 강점 | 자기평가 | 백분위 |
|---|---|---|
| 협상 | 8/10 | 상위 10% 추정 · 근거: 3년 연속 팀 영업 1위, 연 계약액 20억 |
| 자기인식 | 9/10 | 외부 검증 지표 없음 |

(예시 수치다. 실제 보고서에는 사용자 vault의 실적만 쓴다)

근거가 없으면 백분위를 비운다. 자기보고만으로 "한국인 상위 N%"를 만들어내는 건 금지다.

**3. 정식 검사 결과** — 사용자가 검사를 받고 결과를 주면 그대로 쓴다. 이때만 백분위를 추정 표시 없이 쓴다.

- VIA-IS 성격강점 검사 (24강점, 무료) — 강점 순위
- IPIP Big5 한국 규준 (Lim & Ham 2003) — 5요인 백분위
- ECR-R 36문항 — 애착 유형

사용자가 "내 강점 상위 몇 %야"라고 물으면, 근거 있는 항목은 추정으로 답하고 없는 항목은 왜 못 내는지 한 줄로 말한 뒤 위 검사를 안내한다.

### 종합 형식

```
## 🪞 종합

■ 한마디로
[한 문장 + 평소 움직이는 방식 4~5개]

■ 강점
[1~5개, 각 항목 한 줄 풀이]

■ 조심할 점
[1~5개, 위험 신호 포함]

■ 지금 필요한 것
[각 항목마다 왜 이게 통하는지 한 줄]
```

### 깔끔한 문서로 보이기 위한 금지

보고서와 영역별 풀이는 문서다. 채팅 메모처럼 보이면 안 된다.

- 본문에 코드 서식(백틱), 화살표(→ ↔), 등호(=)를 쓰지 않는다
- 키워드 줄 말고는 본문에 가운뎃점 나열을 쓰지 않는다
- 데이터 박스 외에 태그 줄·메모 줄을 따로 만들지 않는다
- 장면이 안 그려지는 비유는 풀어쓴다. "그 눈이 자기 자신에게 겨눠질 때" 같은 문장 금지
- 출처 없는 일반화 금지. "이 조합은 흔치 않습니다" 같은 문장은 근거가 없으면 뺀다
- 굵게는 문서 하나에 한두 번까지

### 좋은 예

> ■ 타고난 기질
> 사람의 속과 흐름을 먼저 읽는 기질을 타고났습니다. 대화가 어디로 흘러갈지, 상대가 무엇을 원하는지가 말이 끝나기 전에 보이는 편입니다.
>
> ■ 잘 풀리는 자리
> 이 힘은 사람이 걸린 일에서 가장 크게 빛납니다. 협상 자리와 콘텐츠에서 이 감각이 실제 성과로 이어졌습니다.
>
> ■ 조심할 자리
> 다만 같은 감각이 자기 자신을 향하면 쉽게 무거워집니다. 감정을 꺼내지 않고 혼자 쌓아두다가, 한계에 이르러 한 번에 터뜨리는 흐름이 반복됩니다.
>
> ■ 지금 필요한 것
> 더 깊이 들여다보는 것보다, 결정과 행동 사이에 시간을 두는 장치가 먼저입니다. 큰 결정일수록 하룻밤 자고 다시 보는 것만으로 흐름이 달라집니다.

### 나쁜 예

> 보는 눈은 최상위인데, 그 눈이 자기 자신에게 겨눠질 때 가장 아프게 작동한다.
> `자각 8 ↔ 조절 4 = 4점 차`
> 이 조합은 흔치 않다. 8을 9로 올려도 4는 안 움직인다.

추상 비유, 코드 서식과 기호, 본문 숫자, 출처 없는 일반화, 단문 끊기가 다 들어 있다.

### 인용 가능한 외부 레퍼런스 (필요 시만)

보고서가 사용자 입력을 일반 패턴과 비교하는 경우, 검증된 출처만 인용:

- 애착 유형 분포: Bartholomew & Horowitz 1991
- ADHD 성인 자기조절 갭: Barkley 2015 메타분석
- VIA 24 강점 분류: Peterson & Seligman 2004
- ACE 어린시절 역경: Felitti et al. 1998 (CDC-Kaiser)
- Big5 한국 규준: IPIP-K, Lim & Ham 2003
- 한국 30대 평균 자산: NABO 등 공공 통계

사용자 응답을 위 프레임의 언어로 매핑할 때는 반드시 "추정"임을 표시한다. 정식 검사 결과가 아니다.

### 보고서 다음 — 이렇게 쓰면 됩니다 (필수)

보고서 맨 끝에 아래 안내를 붙인다. 보고서를 읽고 "그래서 이걸로 뭘 하지?"에서 멈추지 않게 하는 게 목적이다. 보고서의 일부라 합니다체로 쓴다.

```
## 🧭 이제 이렇게 쓰시면 됩니다

보고서는 출발점입니다. 이 vault는 고민이 생겼을 때 꺼내 쓰는 도구입니다.
상황을 있는 그대로 던지면, 채워둔 문서를 근거로 답합니다.

■ 이직·커리어 고민
"이직 제안이 왔어. 연봉은 20% 오르는데 초기 스타트업이야. 갈까?"
"지금 회사에 3년 더 있으면 뭐가 남을지 봐줘"

■ 지금 하는 일 상담
"상사가 내 기획안을 계속 반려해. 어떻게 풀어야 할까?"
"요즘 일이 손에 안 잡혀. 번아웃인지 봐줘"
"지금 하는 업무 방식 봐줘. 더 나은 방법이 있을까?"

■ 연애 상담
"만난 지 한 달 됐는데 서운한 게 쌓였어. 지금 말해도 될까?"
"헤어지자는 말을 들었어. 연락하고 싶은데 해도 될까?"

■ 재테크 점검
"요즘 오르는 종목이 있는데 들어가고 싶어. 내 룰에 걸리는 거 있어?"
"이번 달 매매 기록이야. 내가 정한 룰 어긴 거 있나 봐줘"

■ 큰 결정 앞에서
"퇴사할지 고민이야. 의사결정 필터 돌려줘"

■ 정기 점검
"이번 주 돌아봐줘"
"이번 분기 목표 점검해줘"

■ 더 깊이 풀어보기
1. 나와 맞는 연인 유형
2. 나와 맞는 직업·역할
3. 나와 맞는 사이드 방향
4. 내 돈 그릇과 재물 패턴
5. 인간관계에서 자주 빠지는 함정
6. 가족이 지금의 나에게 준 영향

사주·별자리도 같이 보고 싶으면 "사주로도 봐줘"라고 하시면 됩니다.
```

### 상담 답변 룰

상담은 풀이가 아니다. 결정을 내리게 돕는 답이다. 분석을 더 얹지 말고 결정으로 좁힌다.

형식:

1. **결론 한 줄** — 먼저 말한다
2. **근거** — vault의 어느 문서, 무엇에 비췄는지 2~3줄 (1~3순위, 위험 신호, 비협상 룰 등)
3. **지금 할 것** — 1~3개. 오늘이나 이번 주 단위로
4. **가드** — 사용자 약점에 걸리는 지점이 있으면 한 줄 (30분 룰, 메모장 24시간 등)

상담은 대화라서 CLAUDE.md 일반 대화 워딩 룰을 따른다.

영역별 근거 문서:

| 상담 | 근거 문서 |
|---|---|
| 이직·커리어 | career_style (이직 5필터) · philosophy (1~3순위) · self_profile (위험 신호) |
| 지금 하는 일 | career_style (번아웃 트리거·회복 프로토콜) · self_profile (루프·강점) · roadmap (분기 목표) |
| 연애 | love_style (데이트 룰·결혼 필터) · relationship_protocol (침묵 룰·금지 메시지) · self_profile (루프) |
| 재테크 | investment_style (비협상 룰·위험 신호·자산 배분) · philosophy (돈의 순위) |
| 큰 결정 | life_compass (의사결정 필터 5개) · philosophy |
| 정기 점검 | roadmap · life_compass 자문 루틴 |

근거 문서가 비어 있으면 그 영역 질문 2~3개를 한 번에 묶어 먼저 채우고 답한다.

영역별 선:

- **재테크** — 종목·상품·매수 시점을 추천하지 않는다. 투자 자문 자격이 없는 도구다. 사용자가 스스로 박은 비협상 룰·위험 신호·자산 배분에 비춰 지금 결정이 룰 안인지 밖인지만 점검한다. 룰이 아직 없으면 룰부터 같이 만든다
- **연애** — 상대의 속마음을 단정하지 않는다. 사용자가 할 행동을 정하는 데 집중한다
- **이직·업무** — 회사나 사람을 평가하지 않고, 사용자 기준(1~3순위·번아웃 트리거)에 맞는지로 판단한다

### 영역별 풀이 작동 룰

사용자가 안내의 "더 깊이 풀어보기"에서 하나를 고르거나 같은 걸 직접 물으면 아래 흐름으로 답한다. 보고서의 영역 카드 하나를 크게 펼친 모양이다. 문체와 "깔끔한 문서로 보이기 위한 금지"는 보고서와 똑같이 적용한다.

**1. 사주 같이 볼지 사용자에게 묻기**

`saju.md`·`zodiac.md`가 채워져 있으면 답하기 전에 한 번 묻는다:

```
사주(또는 별자리) 풀이도 같이 봐줄까?
사주가 내 답변이랑 같은 방향을 가리키는지, 다른 방향을 가리키는지 볼 수 있다.
```

채워져 있지 않으면 묻지 않고 vault 데이터로만 답한다.

**2. 풀이 형식**

```
## 💞 나와 맞는 연인 유형

> [한 줄 요약]

| 항목 | 값 |
|---|---|
| 잘 맞는 사람 | [짧게] |
| 조심할 사람 | [짧게] |
| 시기 | [짧게] |
| 두 풀이 일치도 | 🟢🟢🟢🟢⚪ 강한 일치 |

■ 나에게 맞는 사람
[2~3문장. 사용자가 채운 답을 근거로 푼다]

■ 잘 풀리는 자리
[2~3문장]

■ 조심할 자리
[2~3문장. 위험 신호와 연결]

■ 사주로 보면
[3~4문장. saju.md 박제 데이터에서만]

■ 두 풀이가 만나는 곳
[2~3문장. 같은 쪽을 가리키는 곳 먼저, 갈리는 곳은 그다음]

■ 지금 필요한 것
[1~2문장. 처방은 vault 자체 약점에서만. 시기 신호가 있으면 가드로 붙인다]
```

- 첫 소제목만 영역마다 다르고 나머지는 공통이다
  - 연인 유형: ■ 나에게 맞는 사람
  - 직업·역할: ■ 나에게 맞는 일
  - 사이드: ■ 나에게 맞는 사이드
  - 돈: ■ 타고난 돈 그릇
  - 인간관계: ■ 자주 빠지는 함정
  - 가족: ■ 가족에게서 온 것
- 데이터 박스 항목도 영역에 맞춘다. 연인이면 잘 맞는 사람·조심할 사람·시기, 직업이면 맞는 일·피할 일·시기 식이다
- 일치도 칸과 「사주로 보면」「두 풀이가 만나는 곳」은 사주를 같이 볼 때만 넣는다
- 별자리를 같이 볼 때는 「별자리로 보면」으로 바꾸고 `zodiac.md` 박제 데이터에서만 푼다

「사주로 보면」에서 푸는 것:

- 사주 풀이는 사용자 기질만 풀지 않는다. 연인 유형을 물었으면 짝의 그림을 네 축으로 푼다. 짝의 성격(일간·십신·오행 균형), 짝의 외모(정재(남)·정관(여) 같은 배우자 자리와 신살), 짝의 일과 환경(인성은 가정·배경, 관성은 외부 받침), 시기 신호(대운·세운으로 본 지금부터 1~3년)
- 직업: 일간 기질, 식상·관성 균형, 어떤 일이 잘 맞는지, 시기
- 돈: 재성 분포, 비겁 충돌, 어떤 돈이 잘 맞는지, 시기
- 가족: 인성(부모)·비겁(형제) 자리, 영향 패턴, 회복 길
- 사주 용어는 일상어로 풀어쓴다. 어휘는 "기질적 경향·강약 영역·잘 맞는·자연스럽게 끌리는"만 쓰고 "운명 결정" 어휘는 쓰지 않는다

「두 풀이가 만나는 곳」에서 맞춰 보는 것:

- 같은 축끼리 비교한다. 짝의 성격, 짝이 받쳐줘야 할 내 약점, 시기 신호에 대해 두 풀이가 각각 뭐라고 했는지
- 같은 쪽을 가리키는 곳을 먼저 쓰고, 갈리는 곳을 그다음에 쓴다
- 사주에만 있는 축(외모·환경 같은 것)은 답변에는 없던 축이라고 밝히고, 실제 끌림에 작동했을 수 있다는 정도로만 덧붙인다

일치도 라벨 (데이터 박스 칸에 쓴다):

- 🟢🟢🟢🟢🟢 완전 일치: 모든 축에서 같은 쪽을 가리킴
- 🟢🟢🟢🟢⚪ 강한 일치: 핵심 축 일치, 한 축만 조금 다름
- 🟢🟢🟢⚪⚪ 부분 일치: 큰 방향은 같고 디테일이 갈림
- 🟢🟢⚪⚪⚪ 약한 일치: 일부 영역만 일치
- 🟢⚪⚪⚪⚪ 갈림: 다른 쪽을 가리킴
- ⚪⚪⚪⚪⚪ 완전 다른 좌표

**3. 사주를 안 보면 vault 데이터로만 답**

사용자가 "아니"라고 하거나 사주 문서가 비어 있으면, 일치도 칸과 「사주로 보면」「두 풀이가 만나는 곳」을 빼고 소제목 네 개로 낸다. 사주 문서가 채워져 있는데 "아니"라고 했으면 끝에 한 줄만 붙인다.

```
사주도 같이 보고 싶으면 "사주로도 봐줘"라고 하시면 됩니다.
```

**4. 영역별 vault 문서 매핑**

- 연인 유형 → `love_style.md` + `relationship_protocol.md` + `self_profile.md`
- 직업 → `career_style.md` + `self_profile.md` (시장 자산) + `philosophy.md`
- 사이드 → `side_project_strategy.md` + `self_profile.md` 위험 신호
- 돈 → `investment_style.md` + `philosophy.md` (단계화) + `self_profile.md` 형성 사건
- 친구·동료 → `self_profile.md` 위험 신호·검증된 회복 사례
- 가족 → `self_profile.md` 형성 사건·기본 정보

**5. 영역별 검증 레퍼런스 (필요 시만)**

- 연인 유형 → 애착 분포 (Bartholomew 1991), Gottman 결혼 만족도 4 패턴
- 직업 → Holland RIASEC 6 유형, VIA 24 강점 매핑
- 돈 → 한국 30대 자산 분포 (NABO), 행동경제학 손실 회피 (Kahneman & Tversky)
- 가족 → ACE 어린시절 역경 (Felitti et al. 1998)

**6. 사주·별자리 사용 룰 (절대 룰 재확인)**

- 사주·별자리는 vault 데이터를 **덮어쓰지 않는다**. 항상 vault 답변이 본체, 사주는 비교 노트
- 사주 풀이는 `saju.md` 박제 데이터에서만 끌어온다. LLM이 8자·십신·신살을 직접 추정하지 않는다
- 사주가 vault 답변과 갈리면 **사주가 틀린 게 아니라 다른 좌표계**라는 톤으로
- "사주에 약하니 이렇게 해야 한다" 식 처방 ❌. 처방은 vault 자체 약점에서만 도출
- 사이드처럼 사주 전통에 대응 카테고리 없는 영역에서는 사주 풀이 강제로 끌어붙이지 않는다

### 메뉴 다음 안내

사용자가 한 영역 풀이를 받은 후에는 자연스럽게 다음 메뉴 또는 자유 질문으로 이어진다. AI는 끝마다 *"다른 영역도 볼래?"* 한 줄로 메뉴 다시 띄울 수 있다. 단 강제 안 함.

갱신 주기·백업 안내는 README·QUICKSTART에 이미 있으니 보고서·영역별 풀이 끝에 다시 붙이지 않는다.
